## 目的

{{system_name}} 项目统一使用与现有单体测试 Case 相同的 Excel 格式，减少新功能测试设计时的格式差异。

## 模板结构

- `試験観点`：固定保留参考文件第一个 Sheet 的 16 条试验观点、对象标记、说明、公式和下拉选项。
- `項目総計`：保留判定定义和填写说明；清空作成者、日期等项目专属信息。Case 数按各 Sheet 的「試験観点」非空行统计，结果按实际「最新結果」列统计，空模板显示 0。
- `画面レイアウト判定`：保留表头、样式、公式、下拉选项及通用说明；清空 ESG 专属标题和 Case。
- `画面操作処理判定`：保留表头、样式、公式和下拉选项；清空 ESG 专属标题和 Case。
- `項目チェック判定`：保留表头、样式、公式和下拉选项；清空 ESG 专属 Case。
- `DB書き込み判定`：维持原隐藏状态，保留供后续扩展。

三个 Case Sheet 的「最新結果」列固定提供空白、`OK`、`NG`、`NA` 下拉选项；操作处理 Sheet 的筛选范围覆盖全部模板 Case 行。

## 非功能要求

- 不改变 Sheet 名称与顺序。
- 不丢失单元格样式、合并单元格、冻结窗格、筛选、打印设置和数据验证。
- 采用 OOXML 最小修改，避免工具重新保存导致扩展数据验证丢失。
- 模板不得残留 ESG 功能名、人员姓名、日期或具体测试数据。
- 清除参考文件绝对路径、作者、最后修改者、项目专属打印页眉、无效隐藏名称及旧版 Office 样式名称；公式设为打开时自动全量重算。

## 验收标准

- AC-01：模板可由 Excel 或 LibreOffice 正常打开。
- AC-02：`試験観点` 的 B2:E18 内容、公式、样式和下拉选项与参考文件一致。
- AC-03：其余 Sheet 不含 ESG 专属 Case，但保留可填写结构。
- AC-04：空模板汇总 Case 数为 0；录入 Case 后，汇总公式与 Case Sheet 名称、实际结果列保持一致。
- AC-05：工作簿 OOXML ZIP 结构完整，Sheet 顺序和可见性符合本设计。
- AC-06：三个 Case Sheet 的「最新結果」列均可选择空白、`OK`、`NG`、`NA`。
