# Examples

## 按功能建目录（第一步）

```bash
# 例：项目仓库根目录
mkdir -p docs/{機能名}/{05_UI設計,06_画面設計書,07_API設計書}
```

然后写入：
- `docs/{機能名}/README.md`
- `docs/{機能名}/機能設計書.md` 或 `06_…` / `07_…` 拆分文件

**错误**：`docs/新機能設計書.md`（根下平铺）  
**正确**：`docs/新機能/機能設計書.md`

## 完整树示例

```text
{项目仓库}/                         # 项目主目录
└── docs/
    ├── {機能名}/
    │   ├── README.md
    │   ├── 機能設計書.md
    │   ├── 06_画面設計書/
    │   │   └── {画面ID}_{画面名}.md
    │   ├── 07_API設計書/
    │   │   ├── openapi.yaml
    │   │   └── {API ID}_{API名}.md
    │   └── {対象}_校验一覧.md
    └── {别的機能名}/
        ├── README.md
        └── …
```

## Invoke

- 「为 {機能名} 写設計書，按功能分文件夹」
- 「在 docs 下新建 XXX 機能目录并写 06 画面」

## Future 06 / 07 片段

（内容同前；路径均带 `docs/{機能}/` 前缀）

## 遗留迁移

| 旧 | 新 |
|----|-----|
| `docs/{機能名}_設計書.md` | `docs/{機能名}/機能設計書.md` |

新文档只用功能文件夹；迁移时可在旧文件顶部加一行：`> 已迁至 docs/{機能名}/`
